Map data and styles.

- `world_land.geojson`: the offline world outline from the previous OurNet
  prototype, Natural Earth land geometry (public domain). Used by the
  Locations page.
- `style_light.json`, `style_dark.json`, `sprite.json`, `sprite.png`: the map
  styles. Generated by `tool/map_style.dart` from OpenFreeMap's "Liberty" style
  (OpenMapTiles schema; the style code is BSD-licensed, the data is ODbL, so
  the map shows "© OpenStreetMap contributors" and "OpenFreeMap © OpenMapTiles").
  They are bundled so the map is styled with no network.

The vector tiles themselves come from OpenFreeMap (`tiles.openfreemap.org`),
which needs no key. That is the one remote service the map uses, and only for
tiles; it can be switched off in Maps > Offline maps ("Use the internet for
maps"), after which only saved areas and tiles already seen are drawn. No
geocoding service, routing service or location telemetry is used.
